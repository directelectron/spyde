**Find Vectors** used to start with whichever automatic settings had arrived when you clicked Compute. The spot size estimated from the pattern and the neural calibration land a moment after the caret opens, so an early click could run the whole batch with the defaults instead. Compute is now greyed out and reads "Calibrating…" until both have arrived. A spot size or threshold you set by hand in the meantime is no longer replaced when they do.
