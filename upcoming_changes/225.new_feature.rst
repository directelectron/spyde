Find Vectors (neural) has a new **Centre** choice. *Network decode* keeps the detector's own centres, as before. *Mask centroid* re-places every disk on the raw frame at full resolution, using the centroid of the disk's outline rather than its brightness, so unevenly lit disks are centred on their edge. *Fast centre network F3* and *F5* do the same with small networks that also say how sure they are of each centre; use that number to rank vectors, not as an absolute error bar. A network leaves a disk where the detector put it when it is unsure. All are skipped for spots under 5 px, where refining makes centres worse. The live preview and Compute use the same choice.
