Find Vectors (neural) has a new **Centre** choice. *Network decode* keeps the detector's own centres, as before. *Mask centroid* re-places every disk on the raw frame at full resolution, using the centroid of the disk's outline rather than its brightness, so unevenly lit disks are centred on their edge. A centre-refining network can be added to the model list later and will appear in the same menu. It reports how sure it is of each centre, which becomes the vector's sigma, and leaves a disk where the detector put it when it is unsure. The live preview and Compute use the same choice.
