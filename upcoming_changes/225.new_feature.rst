Find Vectors (neural) has a new **Centre** choice. *Network decode* keeps the detector's own centres, as before. *Mask centroid* re-places every disk on the raw frame at full resolution, using the centroid of the disk's outline rather than its brightness, so unevenly lit disks are centred on their edge. A centre-refining network can be added to the model list later and will appear in the same menu. The live preview and Compute use the same choice.
