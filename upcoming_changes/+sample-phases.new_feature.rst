A sample is made of phases now, and a phase is what it is made of AND the structure that indexes it. Those used to be apart — the dock held a flat element list, the orientation wizards held .cif paths, and the COD search silently read the first to fill the second — which could not describe a two-phase sample at all: the query asks for a structure containing EXACTLY the elements given, so a Cu/Nb sample searched as one composition asks for a Cu-Nb compound and gets nothing back, while fcc Cu and bcc Nb are one query each. The dock's Composition section now shows one group per phase with ``&`` between them (and a ``&`` button to add one), each with its structure beside the chips; both orientation wizards' Load tabs became a single ＋ Add phase that opens the same editor, where a phase gets its elements from the periodic table and its structure from either a .cif or a COD search scoped to that phase's elements, listed inline in its row. A structure chosen anywhere is recorded on the dataset, so it survives closing the caret and is visible outside it for the first time. ``Sample.elements`` and ``Sample.composition`` are unchanged — they remain the flat union that EELS edge suggestion and EDS quantification read.
