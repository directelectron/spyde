Every diffraction vector found with the neural method now carries a **confidence** (how sure the network is that a disk is there, 0–1) and a **sigma** (one standard deviation of its centre, from the disk's counts and the network's response width). Vectors the network is unsure of are drawn faint on the diffraction pattern. Vectors saved by earlier versions still open, with the two new columns empty; NXCORR and DoG leave them empty too.
