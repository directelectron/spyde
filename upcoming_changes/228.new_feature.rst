Find Vectors (neural) can now **adapt a centre network to the scan you are working on**. With F3, F5 or another centre network chosen, press *Adapt*: SpyDE fine-tunes a copy of it in the background, using the scan's own Friedel pairs and lattice as the teacher, and checks the copy on rows it never trained on. A card then shows the before/after numbers. If the copy is better it becomes the Centre choice for this session, and *Save for this dataset* keeps it for later sessions. Scans with too few indexed reflections (sparse or amorphous data) are declined before any training.
