Center Zero Beam now makes the centered beam the origin of the detector axes, on patterns and on vectors alike, so strain and orientation read every spot relative to the zero beam. Editing an axis offset after centering now moves the axes of the plot you are looking at, and the Axes table shows the centered node's calibration instead of the original's. Editing an axis scale now recalibrates that axis on every node of the dataset (a rebinned node by the same factor), keeping each node's origin where it was.
